🌐 Cấu Hình Egress Proxy Cho Dola

      
    

    

      

        Dola (ByteDance) yêu cầu IP mạng thuộc khu vực Nhật Bản (JP) hoặc Hàn Quốc (KR). Nếu server chạy tại Việt Nam hoặc các quốc gia khác mà không qua proxy, request tới Dola sẽ bị từ chối kết nối hoặc yêu cầu captcha.
      

      
      

        
Cách cấu hình trong file .env.local:

        
# Proxy HTTP (VD: Clash, v2ray, vmess local port)
DOLA_PROXY=http://127.0.0.1:7890

# Hoặc SOCKS5 Proxy
# DOLA_PROXY=socks5://127.0.0.1:10808

# Proxy có user/password:
# DOLA_PROXY=http://username:password@proxy-ip:port

      


      

        💡 Mẹo: Nếu bạn bật VPN toàn hệ thống (Tun Mode hoặc System Proxy) trên máy tính chọn vị trí Japan / Korea, bạn có thể để trống DOLA_PROXY= trong file .env.local.
